# Noted

Three independent note-taking implementations: MUI, Angular Material, and Google Material 3.

The three-version project source is supplied as `noted-project.tar.xz`. Upload it to `source/noted-project.tar.xz` on the `main` branch. The GitHub Pages workflow expands the archive and builds all versions.

After the first push, check **Settings → Pages → Build and deployment** and choose **GitHub Actions** as the source if Pages is not already enabled.

When deployed, the site routes are `/Noted/`, `/Noted/mui/`, `/Noted/angular/`, and `/Noted/material3/`.
